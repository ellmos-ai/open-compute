1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

open-compute is engineered under strict architectural and governance
invariants: 100% Local-First, Zero-Egress by default, unprivileged user-mode
execution (RunAsInvoker), and fail-closed safety gate interception. The core
agent loop has zero mandatory external runtime dependencies and executes
entirely within the Python standard library. Optional extras (anthropic, openai,
playwright, mss, Pillow, uiautomation, windows-capture, watchdog, clirec, mcp)
are dynamically and lazily imported only when explicitly selected by the
operator.

All direct, optional, and development dependencies utilized across open-compute
are distributed under strictly permissive and free open-source licenses (MIT,
Apache-2.0, PSFL-2.0, HPND). There are zero copyleft, GPL, or AGPL-style viral
dependencies, guaranteeing complete operational safety for enterprise
integration, autonomous agent fleets, and security-critical deployments.
Canonical copyright and ecosystem attributions are formally preserved in the
root NOTICE file.

3. ZERO-COPYLEFT ISOLATION GUARANTEE & RUNASINVOKER CERTIFICATION
================================================================================

1. Zero-Copyleft Isolation Guarantee:
   All core runtime dependencies operate strictly under permissive open-source
   licenses (PSFL-2.0, MIT, Apache-2.0, HPND). The codebase, build definitions,
   and runtime interfaces are completely free of GPL, AGPL, LGPL, SSPL, or
   reciprocal copyleft obligations.

2. Unprivileged Execution (RunAsInvoker):
   open-compute enforces unprivileged user-mode execution under INV-USR-06.
   All GUI interactions, coordinate normalizations, and action dispatches operate
   strictly within non-elevated user context without requiring administrative
   or root privileges.

3. Zero-Egress Perimeter:
   Under INV-EGR-07, default and mock operations initiate zero network
   connections, transmit no telemetry, and execute entirely on local system
   resources. Volatile API secrets (INV-SEC-08) are never persisted to disk.
